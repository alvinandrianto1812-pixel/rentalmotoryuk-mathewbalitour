## ✨ Fitur Website

- **Halaman Rental Motor** - daftar 10 unit motor dengan harga harian, mingguan, bulanan
- **Halaman Bali Tour** - 5 paket full day tour dengan armada Toyota & Isuzu
- **WhatsApp Order Builder** - form pemesanan interaktif 5 langkah, langsung kirim ke WA
- **Dark/Light Mode** - toggle tema dengan preferensi tersimpan
- **Desain Luxury** - glassmorphism, gold accent, animasi halus
- **SEO Optimal** - structured data JSON-LD, sitemap, Open Graph, Twitter Card
- **Fully Responsive** - mobile-first design

## 🚀 Deployment

Website di-deploy otomatis via **Vercel** setiap kali ada push ke branch `main`.

Untuk deploy manual:
1. Fork/clone repo ini
2. Connect ke [Vercel](https://vercel.com)
3. Import repo → Vercel auto-detect sebagai static site
4. Deploy ✅

---

## 📦 Cara Menjalankan Lokal

Tidak butuh build step - cukup buka file HTML langsung, atau gunakan live server:

```bash
# Dengan VS Code Live Server extension
# Klik kanan index.html → Open with Live Server

# Atau dengan Python
python -m http.server 3000
```
